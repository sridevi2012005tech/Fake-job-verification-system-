# 🚀 Fake Job Offer Detection System

### AI & DS Mini Project | Work in Progress | Building in Public

## 📌 Problem Statement
Freshers and students often receive fake job offers via WhatsApp/Email with "registration fees" or "work from home" scams. This project aims to detect and flag suspicious job postings using Data Science techniques.

## 🎯 Project Goal
To build a simple ML model that analyzes job descriptions and predicts if it's **FAKE** or **REAL** based on keywords, patterns, and common scam tactics used in India.

## 🛠️ Tech Stack Planned
- **Language:** Python
- **Libraries:** Pandas, Scikit-learn, NLTK 
- **ML Concepts:** NLP, Text Classification, Logistic Regression
- **Platform:** Google Colab / Jupyter Notebook
- **Future:** Streamlit web app
